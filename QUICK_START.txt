1️⃣  VERCEL (Recommended)
    $ npm i -g vercel
    $ vercel
    → Auto-deploy from git, best performance

2️⃣  GITHUB PAGES
    $ git push origin main
    → Settings → Pages → Select main branch
    → Free, integrated with GitHub

3️⃣  NETLIFY
    Drag folder to netlify.com
    → Instant deploy, free tier

4️⃣  ANY STATIC HOST
    Upload all files via FTP/S3/SFTP
    → AWS S3, Firebase, Digital Ocean, etc.
