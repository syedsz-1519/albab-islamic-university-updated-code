SUPPORT & CHANGES:
==================

To update content:
1. Open Albab Islamic University.html in any text editor
2. Find the config arrays (near the top, after <style> tag)
3. Edit the values
4. Save and refresh the browser
5. Test on mobile (use DevTools)

To change design:
1. Edit CSS variables in :root block
2. Or modify .class selectors in the <style> block
3. Save and refresh

See UPDATE_GUIDE.md for step-by-step examples.
