⚙️ EDITABLE ARRAYS (Top of HTML):
──────────────────────────────────

PROGRAMMES (Events):
────────────────────
window.PROGRAMMES = [
  {
    title: "Event Name",
    date: "2026-11-05",           ← Use YYYY-MM-DD format
    dateDisplay: "05 Nov 2026",
    time: "10:00 AM to 02:00 PM",
    venue: "Location, City",
    desc: "Event description",
    type: "talk",                 ← 'talk', 'course', 'workshop', 'ongoing'
    poster: null                  ← Use "images/poster.jpg" or null
  }
]

BRANCHES (Study Fields):
────────────────────────
window.BRANCHES = [
  {
    name: "Hadith",
    desc: "One-line description",
